# IEDC — Govt. Polytechnic College Attingal

> **Build. Innovate. Launch.**  
> Official website for the Innovation and Entrepreneurship Development Cell (IEDC) at Government Polytechnic College Attingal, Kerala.

🌐 **Live Site:** [Click here](https://iedc-gptc-attingal.netlify.app)

---

## About

The IEDC at GPTC Attingal is a student-run innovation hub backed by [Kerala Startup Mission (KSUM)](https://ksum.in). This website serves as the public face of the cell — showcasing programs, the executive team, and providing a gateway for new student members to join.

---

## Features

- Responsive single-page layout
- Animated stat counters (Members, Events, Projects, Years)
- Terminal-style info block with IEDC mission overview
- Program cards: Workshops, Hackathons, Startup Support
- Executive team section with department filters
- External links to KSUM, DTE Kerala, Startup India
- Mobile-friendly navigation

## Deployment

The site is deployed via **Netlify** with automatic deploys from the main branch.

To deploy your own fork:
1. Push the repo to GitHub
2. Connect the repo to [Netlify](https://netlify.com)
3. Set publish directory to `/` (or wherever `index.html` lives)
4. Deploy ✅
